# 大象超市

移动端超市首页静态展示，手机双列瀑布流，平板三列，电脑四列。

直接用浏览器打开 index.html。图片、样式、图标字体均已内嵌，可单独发送 HTML 文件，无需外网加载素材。assets 保留原始素材。

包含本地商品搜索、推荐筛选、购物车展示和领券提示，不提供真实交易和配送。

素材：用户提供的参考截图（分类和首屏促销图片），以及 [DummyJSON groceries](https://dummyjson.com/products/category/groceries) 商品图。

图标：[Remix Icon 4.6.0](https://github.com/Remix-Design/RemixIcon)，Apache-2.0。

GitHub Pages 从 main 分支根目录发布。
